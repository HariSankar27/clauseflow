# clauseflow

Turns contract PDFs into validated, evidence-backed records, with precision
and recall published against a real subset of the CUAD dataset.

![CI](https://github.com/HariSankar27/clauseflow/actions/workflows/ci.yml/badge.svg)

## Why this exists

An LLM extracting "the governing law is Delaware" from a contract is only
useful if that claim can be checked. clauseflow requires every extracted
field to come with a verbatim quote from the source document, then throws
out any field whose quote doesn't actually appear in the text - the same
evidence discipline as the resume verifier in
[jobpilot](https://github.com/HariSankar27/jobpilot), applied to contracts.

## Quickstart

    cp .env.example .env      # add GOOGLE_API_KEY
    docker compose up -d
    uv run alembic upgrade head
    uv run clauseflow extract path/to/contract.pdf

## Dataset and licensing

`evals/datasets/contracts/` contains 7 real contracts and their ground-truth
clause annotations from the **Contract Understanding Atticus Dataset (CUAD)
v1**, © The Atticus Project, licensed **CC-BY-4.0**
([theatticusproject/cuad](https://huggingface.co/datasets/theatticusproject/cuad)).
The contracts themselves are public SEC filing exhibits.

## Safety and limitations

A field with no verbatim match in the source document is reported as missing,
never guessed. This does not catch a fabrication that happens to quote real
but irrelevant text from the document - see `docs/decisions/` for what M4's
self-correction/confidence-routing work would add.

## Roadmap

M0-M3 (MVP): Docling parsing, evidence-verified LangGraph extraction,
Postgres storage, a real CUAD-subset eval.
M4-M6 (not yet built): self-correction retries, confidence-based review
queue, ablation studies, chunking for longer contracts.
